# Veysin AI

Android starter app for Veysin AI.

## Included
- AI Chat entry
- AI Image entry
- AI Video entry
- AI Voice entry
- Translator entry

This starter currently provides the app shell and navigation placeholders. Each AI feature needs a provider/API integration before it can perform AI requests.

## Build
Run the GitHub Actions workflow **Build Veysin AI APK** from the Actions tab, or push to the main branch. Download the artifact named `VeysinAI-debug-apk`.
